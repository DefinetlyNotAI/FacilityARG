Hi!

First, this is **not a virus or malware**.

This is an **emulated shell** that will fall back to PowerShell for any commands it doesn’t recognize. This means **PowerShell must be installed** on your system.

---

Supported OS: Windows only.

---

To run the program, simply execute `vessel.exe`.

All generated puzzles, progress, and lore will be saved in the folder `./== GENERATED ITEMS ==` located next to `vessel.exe`. For best results, run `vessel.exe` in its current directory.

Have fun, and see you at the end!
